## ❓ FAQ

### Do I need to run it as Administrator?

No. This repository contains reference material and does not include a program that attaches to the game.

### Can antivirus software detect this repository?

The repository contains informational content rather than a bot executable. Always review downloaded files from external sources before opening them.

### Is it compatible with Windows 11?

The reference materials can be viewed on Windows 11. They do not provide a functional Windows application.

### Does it automate farming or gathering?

No. It explains farming and gathering terminology but does not automate character actions or interact with Guild Wars 2.

### Are botting tools allowed in Guild Wars 2?

ArenaNet prohibits unattended gameplay and third-party programs that automate gameplay. Violations can result in account suspension or termination. Review the official policies before using third-party tools.
